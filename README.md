# Tina - AI Insurance Recommendation 🧠🚗

Tina is a full-stack web application that recommends users the best car insurance plan using conversational AI powered by Google Gemini.

## 🧩 Features

- Conversational AI chatbot named **Tina**
- Recommends one of 3 insurance plans:
  - Mechanical Breakdown Insurance
  - Comprehensive Car Insurance
  - Third Party Car Insurance
- React-based frontend
- Node.js backend connected to Google Gemini API
- Dockerized with `docker-compose` for easy development
